cxvm: Cex Version Manager

The cross-platform version manager for Cex runtimes - seamlessly download cxvm to setup cexr.

What is cxvm?

Just like nvm (Node Version Manager) manages Node.js versions, cxvm manages multiple Cex toolchain releases on your computer. It automatically downloads cross-platform packages, installs native archives into ~/.cxvm/versions/v<version>, configures the cexr runtime runner and cexp compiler, creates clean symlinks to ~/.cxvm/current, and validates your native Cex toolchain with zero C++ dependency.
